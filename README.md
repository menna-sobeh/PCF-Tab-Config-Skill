# PCF Tab Config skill

A Codex skill that collects tab settings and developer-provided FetchXML, then produces JSON for a PCF tab control.

## Install for Codex

Clone this repository, then copy the `pcf-tab-config` folder into your personal skills directory:

- `~/.agents/skills/pcf-tab-config/`

Or put it in a project's `.agents/skills/` folder to share it with that project’s contributors. Start a new Codex session and invoke it with `$pcf-tab-config`. If it does not appear, restart Codex.

## Contents

- `pcf-tab-config/SKILL.md` — skill instructions
- `pcf-tab-config/agents/openai.yaml` — display name and starter prompt
